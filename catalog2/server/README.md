# AL-TOQA Backend

هذا الـ Backend يحول طلبات عروض الأسعار وتسجيل دخول الأدمن إلى عمليات حقيقية على الخادم.

## التشغيل

1. ثبّت Node.js 18+.
2. افتح Terminal داخل مجلد `server`.
3. انسخ `.env.example` إلى `.env`.
4. غيّر `ADMIN_PASSWORD` و `JWT_SECRET`، واضبط `SITE_URL` على دومين الموقع عند النشر.
5. لإرسال الطلبات إلى البريد، أدخل بيانات SMTP. مع Gmail استخدم App Password.
6. شغّل:

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000`.

## ما أصبح حقيقيًا؟

- تسجيل دخول الأدمن يتم عبر API ويصدر JWT بدل كلمة مرور داخل JavaScript.
- طلب عرض السعر يُحفظ في `server/data/quotes.json` على الخادم.
- إذا تم إعداد SMTP، يصل إشعار طلب العرض إلى `QUOTE_RECEIVER`.
- API الطلبات محمي بتوكن الأدمن.
- الموقع ما زال يستخدم `localStorage` للمنتجات والإعدادات الحالية حتى لا نكسر بيانات المشروع الحالية.
- `sitemap.xml` و`robots.txt` يتم توليدهما من الخادم باستخدام `SITE_URL`، لذلك لا تحتاج لتعديل روابط `YOUR-DOMAIN.com` يدويًا.

## الإنتاج

قبل رفع الموقع:
- استخدم HTTPS.
- غيّر كلمات المرور والأسرار.
- ضع `CORS_ORIGIN` على دومين الموقع الحقيقي.
- استخدم قاعدة بيانات حقيقية بدل JSON عندما يزيد عدد الطلبات.
