# قاعدة البيانات

شغّل `supabase/setup.sql` في Supabase SQL Editor.

المحتوى الدائم للموقع الآن مخزن في Supabase: `products`, `categories`, `banners`, `quotes`.
الصور تُرفع إلى Supabase Storage. لا يعتمد الموقع على ملفات JSON محلية أو localStorage كمصدر للبيانات.
localStorage يُستخدم فقط لبيانات المتصفح المؤقتة مثل جلسة الأدمن والسلة/بيانات العميل والثيم.
